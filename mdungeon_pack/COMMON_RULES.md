# M_dangeon 共通戦闘仕様（会話で確定した内容）
- 全キャラクターは成人として設定する。
- 属性の基本分類は 口 / 胸 / 尻 / 足 / 全。後から「手」が追加された。
- 通常はMPドレインが主軸。拘束技には予備動作があり、上下左右の隣接マスで発動する（突進技など例外的な発動も存在）。
- MPが0になりフィニッシュすると、敵の種類にかかわらず経験値が大量にドレインされ、敵個体が強化される。
- 一部の特殊技はMPが残っていても経験値を直接ドレインする。
- 経験値ドレイン全般で「レベル漏れ癖」が少しずつ付与・蓄積され、経験値を奪われやすくなる。
- 指定技によるフィニッシュを成功させた敵個体は、上位技を永続的に習得する。戦闘終了後も解除されない。
- 主人公の特定の情けない行動により永続デバフが付与され、敵も強化され得る。具体的なトリガーはキャラごとに提案段階。
- ランク: basic / unique / elite / boss。
- 特殊技は0〜3個。上位技を持たない敵も設計上可能。
